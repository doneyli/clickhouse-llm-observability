# Instructor 00-setup

**DRAFT.** Suggested duration: 15 minutes. Timing is a MEDIUM confidence delivery assessment; adjust after rehearsal.

Use the [learner lesson](../learner/00-setup.md). Start from the named checkpoint before the exercise, not from the complete root solution.

**Frame:** "Everyone should be running the same app before we discuss its traces."

**Show:** Generate 00, show the private config template, run preflight, start both services and ask the wire question.

**Learner work:** Have participants confirm the portal says tracing disabled. Pair anyone blocked on Python or model access with a helper.

**Land:** "The workshop has one setup file and a dedicated project. No trace is expected yet."

**Ask:** "Can everyone get a policy answer? Which error remains?"

**Common pitfalls:** Cloud region/key mismatch is checked after tracing is activated. A provider key can exist but lack model access. Avoid seeding the complete enterprise demo.

**Recovery:** Use the instructor's portal for orientation while setup is repaired. No participant needs access to an instructor secret.

**Advance when:** the learner lesson's verification criteria are demonstrated. If you use a completed checkpoint to catch up, identify which exercise was skipped. Folder changes do not migrate Langfuse configuration or run remote seed scripts.
