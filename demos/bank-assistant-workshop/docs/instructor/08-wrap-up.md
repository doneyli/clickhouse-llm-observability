Use the [learner lesson](../learner/08-wrap-up.md). Start from the named checkpoint before the exercise, not from the complete root solution.

**Frame:** "The loop is reusable beyond this fictional bank."

**Show:** Walk one request from trace to prompt, signal, dataset and comparison. Let participants identify their own first reference examples.

**Learner work:** Each participant names an application, a review signal and a domain owner for references.

**Land:** "Observe behavior, define expected behavior, test a change, then observe the served result."

**Ask:** "What is the smallest decision this loop can help you make next week?"

**Common pitfalls:** Do not drift into production governance or compliance claims. Voice, n8n, self-hosting, APM and calibration need separate preparation.

**Recovery:** Use a single verified trace and one comparison. Finish the loop even if the optional extras are omitted.

**Advance when:** the learner lesson's verification criteria are demonstrated. If you use a completed checkpoint to catch up, identify which exercise was skipped. Folder changes do not migrate Langfuse configuration or run remote seed scripts.
