**DRAFT.** Suggested duration: 25 minutes. Timing is a MEDIUM confidence delivery assessment; adjust after rehearsal.

Use the [learner lesson](../learner/07-evaluation.md). Start from the named checkpoint before the exercise, not from the complete root solution.

**Frame:** "Changing one thing makes a result easier to interpret."

**Show:** Publish candidate with citation instructions only. Compare baseline/candidate on the same dataset version, agent model, judge and concurrency. Rehearse the label setting rollback.

**Learner work:** Ask each pair to select two rows and state whether the candidate helped, harmed or produced inconclusive evidence.

**Land:** "The decision is based on examples and constraints, not a single average."

**Ask:** "What additional test would change your willingness to serve this prompt?"

**Common pitfalls:** Baseline may already cite sources. Eight examples do not establish statistical significance. A label is mutable; record the exact versions served.

**Recovery:** Use the root reference app to run both versions if participants are stuck. Never invent an improvement figure or reuse historical original-demo evidence as this run's evidence.
