# SOP-SVC-03 — Suitability information and best interest

Northwind Life & Annuity · Standard Operating Procedure · Version 2, effective 2025-01-01 · Owner: Annuity Compliance

## 1. Scope and purpose

Products: Deferred annuities — in-force servicing (withdrawals, surrenders, replacements). Jurisdictions: all states.

What the company must know about the consumer, and check, before acting on a recommended annuity transaction.

## 2. Consumer profile

**SVC-BI-001 — Profile incomplete.** For a replacement, or any transaction an agent recommended, the consumer profile must state annual income, liquid net worth, risk tolerance, time horizon and liquidity needs. If any is missing, pend the request and collect it. _(Rule version 1, effective 2024-01-01.)_

**SVC-BI-004 — Liquidity mismatch.** A replacement whose new contract has a surrender period longer than the consumer's stated time horizon locks up money the consumer expects to need. Route it to Annuity Compliance for a best-interest review. _(Rule version 1, effective 2024-01-01.)_

## 3. Senior consumers and compensation

**SVC-BI-002 — Senior consumers.** When the owner is seventy-five or older and an agent recommended the transaction, route it to the senior-investor review desk before processing. _(Rule version 1, effective 2024-01-01.)_

**SVC-BI-003 — Compensation disclosure.** For an agent-recommended transaction, the confirmation must disclose how the agent is paid for it (commission and any non-cash compensation). _(Rule version 1, effective 2024-01-01.)_
