    Organization management API

    Some Enterprise routes also start with /api/public. The badge follows the capability and entitlement, not the URL prefix. Organizations uses the separate instance API and ADMIN_API_KEY. Protected labels and audit reads use a version-pinned native UI RPC adapter, explicitly identified in the inspector. They are Enterprise features without a supported Public API management endpoint in this tested version. SSO configuration and other deployment settings are outside these workflows.
